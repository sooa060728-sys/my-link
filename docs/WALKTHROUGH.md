# 🚶‍♂️ [WALKTHROUGH] 마이링크 (MyLink) 기능 워크스루 가이드

이 문서는 새로 구현된 마이링크 대시보드의 다이얼로그 폼 모달 및 로컬 상태 기능을 한눈에 확인하고 시연할 수 있는 워크스루(Walkthrough) 가이드입니다.

---

## 1. 관리 대시보드 접속 (`/my`)
브라우저에서 `http://localhost:3000/my` 로 이동하면 관리 대시보드가 열립니다.

## 2. 주요 기능별 다이얼로그 사용 시나리오

### ➕ 2.1 새 링크 / 섹션 헤더 추가 다이얼로그
1. 우측 상단의 **`[+ 블록 추가]`** 버튼을 클릭합니다.
2. 상단 탭에서 **`웹사이트 링크`** 또는 **`섹션 헤더`**를 선택합니다.
3. 제목과 URL 주소(예: `https://youtube.com`)를 입력하고 원하는 아이콘(유튜브, 깃허브 등)을 지정합니다.
4. **`[추가하기]`** 버튼을 누르면 목록에 즉시 추가되며 로컬 스토리지에 저장됩니다.

---

### ✏️ 2.2 기존 블록 정보 인라인 수정(Inline Edit) UI
1. 각 링크 카드 우측에 상시 표시된 **`[수정]`** 버튼(✏️)을 클릭합니다.
2. 해당 카드 영역이 즉시 인라인 편집 폼으로 전환되며, 기존 데이터가 자동으로 채워집니다.
3. 추가할 때와 동일한 입력 유효성 검사(제목 1~50자, 올바른 URL 주소, XSS 방지 등)가 적용됩니다.
4. **`[저장하기]`** 버튼을 누르면 파이어베이스 Firestore(`users/anonymous/links/{id}`)에 비동기 저장되고 대시보드에 즉시 반영됩니다.
5. 수정을 취소하려면 **`[취소]`** 버튼을 누릅니다.

---

### 🗑️ 2.3 블록 삭제 확인 모달 (Delete Confirmation Modal)
1. 각 링크 카드 우측에 상시 표시된 **`[삭제]`** 버튼(🗑️)을 클릭합니다.
2. **"정말 삭제하시겠습니까?"** 제목의 삭제 확인 모달이 열립니다.
3. 삭제하려는 링크의 이름과 URL이 표시되며, 빨간색으로 **"이 작업은 되돌릴 수 없습니다"** 경고 문구가 표시됩니다.
4. **`[삭제하기]`** 버튼을 누르면 파이어베이스 Firestore(`users/anonymous/links/{id}`) 및 로컬 상태에서 영구 삭제됩니다.
5. 삭제를 중단하려면 **`[취소]`** 버튼을 누릅니다.

---

### 🎨 2.3 프로필 정보 & 테마 프리셋 설정 다이얼로그
1. 대시보드 상단 컨트롤 바의 **`[프로필·테마]`** 버튼을 클릭합니다.
2. 닉네임, 한줄 소개, 프로필 아바타 이미지 URL을 변경합니다.
3. 6가지 프리셋 테마 중 하나를 선택합니다:
   - **Light**: 깔끔한 밝은 스타일
   - **Dark**: 다크 모드 스타일
   - **Neon**: 형광 에메랄드 네온 스타일
   - **Pastel**: 파스텔 퍼플 톤 스타일
   - **Minimal**: 모던 미니멀 스타일
   - **Gradient**: 파스텔 블루-퍼플 그라디언트 스타일
4. 버튼 스타일(라운드 / 모서리 / 아웃라인)을 고른 뒤 **`[설정 적용하기]`**를 누릅니다.

---

### 🔗 2.4 소셜 아카이브 링크 관리 다이얼로그
1. 상단 컨트롤 바의 **`[소셜 링크]`** 버튼을 클릭합니다.
2. 인스타그램, 유튜브, 깃허브, 트위터, 이메일, 웹사이트 등 매체를 고르고 URL을 입력하여 추가합니다.
3. 등록된 소셜 매체는 공개 프로필 하단에 아콘 바 형태로 표시됩니다.

---

### 📊 2.5 클릭 & 방문 분석 통계 다이얼로그
1. 상단 컨트롤 바의 **`[통계]`** 버튼을 클릭합니다.
2. **총 프로필 방문수(PV)** 및 **총 링크 클릭수** 수치를 한눈에 확인합니다.
3. 각 링크별 누적 클릭수와 전체 대비 클릭 비율(%) 퍼센트 바를 실시간으로 확인합니다.
4. 필요시 **`[통계 데이터 초기화]`** 버튼을 눌러 카운트를 0으로 리셋할 수 있습니다.

---

### 👥 2.6 페르소나 / 프로필 스위처 다이얼로그
1. 상단 컨트롤 바의 **`[프로필 전환]`** 버튼을 클릭합니다.
2. PRD 더미 데이터에 정의된 크리에이터(`creator_hana`), 개발자(`dev_minjun`), 디자이너(`design_yuna`) 프로필로 즉시 전환하거나, 새 사용자 핸들을 입력하여 가입 시연이 가능합니다.

---

## 3. 실시간 미리보기 검증 (`/[username]`)
- 대시보드 상단의 **`[공개 보기]`** 버튼을 누르면 새로운 탭에서 `http://localhost:3000/demo` (또는 해당 username) 페이지가 열립니다.
- 대시보드 다이얼로그에서 수정한 링크, 테마, 버튼 스타일, 소셜 매체가 실시간으로 적용된 것을 확인할 수 있습니다.
